# 🎼 Overview

Tamil Music Player is a lightweight web application designed to provide users with a simple and enjoyable music listening experience.

The application features an elegant interface where users can browse available songs, navigate through playlists, and enjoy music directly from the browser without requiring additional software.

This project demonstrates frontend development concepts such as navigation, audio handling, responsive layouts, and JavaScript interactivity.

---

# 🎯 Project Objective

The goal of this project was to build a browser-based music player while improving knowledge of:

- HTML5 Audio API
- JavaScript DOM Manipulation
- Responsive Web Design
- Interactive User Interfaces
- Event Handling
